# The Spot Sober Lounge App — v1.0

Godot 4.7 starter mobile app for The Spot Sober Lounge.

## Run
1. Open Godot 4.7.
2. Import `project.godot`.
3. Run the project (F6/F5).

## Included
- Mobile 432x900 reference layout with stretch support
- Home, Meetings, Events, VIP, More navigation
- Current meeting schedule seeded from thespotlounge.com (site listed updated 6/10/26)
- External links for events, shop and directions
- Organized `scenes/` and `scripts/` structure
